# Arif Mia — Website Redesign (Demo)

Complete redesign concept for [arifmia.com](https://arifmia.com): an
evidence-led editorial site in the brand's navy + teal theme. See
[`DESIGN.md`](DESIGN.md) for the approved brief, tokens, content rules,
asset provenance, and review record.

## Pages

- `index.html` — Home (offer, services index, process, quotes, FAQ)
- `about.html` — About (story, principles, toolbox, journey)
- `services.html` — All 9 services with mechanisms and deliverables
- `results.html` — 6-month case study with tables, screenshots, limitations
- `contact.html` — Contact + free-audit request form
- `404.html` — Helpful not-found page

## Stack

Static HTML + CSS + vanilla JS. No build step, no dependencies, readable
without JavaScript. Light/dark themes follow the OS unless the visitor
saves a choice.

## Preview locally

```bash
python3 -m http.server 8080
```
