# Arif Mia — Website Redesign (Demo)

Complete redesign concept for [arifmia.com](https://arifmia.com), keeping the current
brand theme (deep navy `#061C43` + teal `#0AA29A` + mint `#EAF1F0`) with a 100% new
design: header, footer, hero, and every page.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — All 9 services
- `results.html` — Case study & testimonials
- `contact.html` — Contact + free audit form
- `404.html` — Custom not-found page

## Stack
Pure static HTML + CSS + vanilla JS. No build step, no dependencies.
Served directly by GitHub Pages.

## Preview locally
```bash
python3 -m http.server 8080
```
